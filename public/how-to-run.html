🚀 خطوات التشغيل
1

ابني المشروع

افتح Terminal في مجلد المشروع وشغّل:

npm run build

ده هيعمل مجلد dist/ فيه كل ملفات الإضافة الجاهزة.

2

ولّد الأيقونات

افتح الملف ده في المتصفح:

dist/generate-icons.html

اضغط "توليد وتحميل جميع الأحجام" → هيتحمّل 4 ملفات PNG (16, 32, 48, 128)

انقلهم لمجلد dist/icons/ وسمّيهم:

dist/icons/icon16.png dist/icons/icon32.png dist/icons/icon48.png dist/icons/icon128.png
3

أضف الأيقونات في manifest.json

افتح dist/manifest.json وضيف الأيقونات:

{ "icons": { "16": "icons/icon16.png", "32": "icons/icon32.png", "48": "icons/icon48.png", "128": "icons/icon128.png" }, "action": { "default_popup": "index.html", "default_title": "ProjectFlow", "default_icon": { "16": "icons/icon16.png", "32": "icons/icon32.png", "48": "icons/icon48.png", "128": "icons/icon128.png" } } }
4

حمّل الإضافة في Chrome

chrome://extensions/

1. فعّل "Developer mode" ↗️

2. اضغط "Load unpacked" 📂

3. اختار مجلد dist/ ✅

  • ✓ افتح Chrome واكتب في العنوان: chrome://extensions/
  • ✓ فعّل "Developer mode" (في أعلى اليمين)
  • ✓ اضغط "Load unpacked"
  • ✓ اختار مجلد dist/ من المشروع
  • ✓ هتلاقي الإضافة ظهرت! ⚡
5

جرّب الإضافة! 🎉

  • ⚡ اضغط على أيقونة الإضافة في Toolbar → هيفتح الـ Popup
  • 📋 أضف مهمة جديدة من الـ Popup
  • 🌐 افتح أي موقع → هتلاقي زر عائم بنفسجي في أسفل الصفحة
  • ⌨️ اختصارات: Alt+Shift+P لفتح الإضافة
  • ⚙️ اضغط "تفاصيل" → "Extension options" لفتح الإعدادات
💡 نصيحة للتطوير

لما تعدّل في الكود، اعمل npm run build تاني وبعدها روح على chrome://extensions/ واضغط زر التحديث ↻ عند الإضافة.

1

جهّز حساب المطور

ادخل على Chrome Developer Dashboard:

https://chrome.google.com/webstore/devconsole

سجّل دخول بحساب Google وادفع رسوم التسجيل لمرة واحدة ($5).

2

اعمل ZIP من الإضافة

cd dist zip -r ../projectflow-extension.zip .

أو على Windows:

cd dist Compress-Archive -Path . -DestinationPath ../projectflow-extension.zip
3

ارفع الإضافة

  • 1 في Developer Dashboard → اضغط "New Item"
  • 2 ارفع ملف projectflow-extension.zip
  • 3 املأ البيانات: الاسم، الوصف، الفئة
  • 4 ارفع Screenshots (1280x800 أو 640x400)
  • 5 ارفع أيقونة كبيرة (128x128)
  • 6 املأ سياسة الخصوصية (موجودة في privacy.html)
  • 7 اضغط "Submit for Review"
4

استنى المراجعة ⏳

المراجعة بتاخد من ساعات لـ 3 أيام في الغالب.

هيوصلك إيميل لما الإضافة تتقبل وتنزل في Chrome Web Store.

⚠️ مهم جداً

تأكد إن:

  • الأيقونات PNG موجودة (مش SVG)
  • manifest.json فيه كل الحقول المطلوبة
  • سياسة الخصوصية واضحة وموجودة
  • الوصف دقيق ومش مضلل
  • الـ permissions مبررة وضرورية
⌨️ اختصارات لوحة المفاتيح
  • ⚡ Alt + Shift + P → فتح الإضافة (Popup)
  • ➕ Alt + Shift + A → إضافة مهمة سريعة
💡 على Mac

استخدم ⌘ Command بدل Alt

🔧 حل المشاكل

الإضافة مش شغالة؟

  • 1 تأكد إن Developer mode مفعّل في chrome://extensions/
  • 2 اضغط زر التحديث ↻ عند الإضافة
  • 3 شوف Console errors: اضغط "Service Worker" في صفحة الإضافة
  • 4 تأكد إن manifest.json سليم (مفيش أخطاء syntax)
  • 5 جرّب تحذف الإضافة وتحمّلها تاني

الزر العائم مش ظاهر؟

  • 1 الزر مش بيظهر في صفحات chrome:// أو chrome-extension://
  • 2 جرّب تفتح موقع عادي زي google.com
  • 3 حدّث الصفحة (F5)
